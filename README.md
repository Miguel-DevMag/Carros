## Sobre o Projeto

O SRT ELITE é uma vitrine digital para veículos super premium, com seções:

- Cabeçalho com identidade visual forte.

- Introdução ao universo automotivo como estilo de vida.

- Carros em Destaque com modelos icônicos.

- Marcas Prestigiadas com história e especialidades.

- Sobre Nós: foco no mercado premium.

- Contato: formulário funcional para comunicação.

O site é desenvolvido com foco na organização semântica do HTML e na consistência visual e textual, sendo uma base sólida para futuras evoluções como catálogo digital ou plataforma de vendas.
